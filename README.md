# Secure AI Data Handling

This Python script demonstrates a simplified approach to protecting digital privacy when using AI. It simulates anonymizing and encrypting user data before it's processed by an AI model, illustrating key concepts for secure data handling.

## Language

`python`

## How to Run

Save the code as `secure_ai_data.py` and run it from your terminal using: `python secure_ai_data.py`
